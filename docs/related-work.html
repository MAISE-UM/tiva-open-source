TIVA — Related Work

Prior art and algorithmic lineage for the simulation in TIVA (STANPUMP and target-controlled infusion, the published PK/PD models, and the reference implementation used for comparison).

This page only lists works that the repository itself cites or that are part of the standard background of the method. For the full citations of the PK/PD models see pk-models.html. TIVA is research and educational software, not a medical device (disclaimer).

Algorithmic lineage

WorkRelation to TIVA
Shafer SL, Gregg KM. Algorithms to rapidly achieve and maintain stable drug concentrations at the site of drug effect with a computer-controlled infusion pump. J Pharmacokinet Biopharm 1992;20(2). The method TIVA's simulation follows (root README): a three-compartment model with an effect-site compartment attached to the central compartment, advanced in small fixed time steps. The same paper describes how to find the infusion rate that brings the effect site to a target; client/model/tciEfctIterate.tsx and tciPlasmaIterate.tsx implement that style of calculation (inactive in the current UI). See simulation-algorithm.html.
STANPUMP (Steven L. Shafer) The well-known computer program for target-controlled infusion (TCI) of intravenous drugs, built on the Shafer and Gregg algorithms. It is the standard reference for the concept TIVA reuses, with one important difference in purpose: STANPUMP computes and drives infusions toward a target, while TIVA reconstructs and displays the concentrations that result from the doses that were actually given.
Octave reference implementation (provided by Utah) The implementation TIVA's client was compared against on 101 cases (347 drug-specific comparisons; maximum deviation 0.103%, median 0.009%; see the root README). The comparison data came from real cases and is not in this repository. It shows the web app reproduces the reference calculations; it is not a clinical validation.
Published PK/PD models (Schnider, Minto, Shafer, Scott/Stanski, Gepts, Ravn, Albrecht, Roy, Cooper/Plaud, Dyck) Supply the parameters. TIVA does not define its own models. Parameters are computed in SQL stored procedures per patient. See pk-models.html.

Target-controlled infusion in practice

Clinical TCI pumps implement the same family of compartment models in device firmware to calculate infusion rates toward a plasma or effect-site target. TIVA does not control any device and makes no claim of equivalence with any pump or vendor implementation. Its inputs are a patient's recorded or entered doses, and its output is a model prediction displayed in a browser.

How TIVA differs

  • Retrospective and descriptive. The input is a dosing history (boluses, infusion starts, rate changes, stops), not a target.
  • EHR-driven. Doses and demographics can be pulled from an EHR over SMART on FHIR and refreshed during the case (ehr-launch-flow.html).
  • Database-defined models. Drugs, units and PK models are rows and stored procedures, so a site can choose or add models without changing code.
  • Browser-side simulation. The calculation runs in the client; the server supplies parameters and stores logs.
